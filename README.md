# 일본어 원서 독해 학습기 (AI 読書ノート)

일본어 원서(소설, 만화, 에세이, 신문 기사 등)의 사진을 올리면, **Google Gemini Multimodal AI**를 거쳐 **한 문장씩 정밀 해석 + 후리가나 + 어휘 정리 + 구문/문법 해설**을 교과서 스타일로 정리해주는 학습 도구입니다.

---

## 🌟 주요 기능

1. **원서 사진 직접 인식 (세로쓰기/후리가나 지원)**
   - 세로쓰기(縦書き) 소설, 만화 말풍선, 작은 후리가나도 Gemini Vision AI가 문맥을 파악해 정확히 독해합니다.
   - 드래그 앤 드롭, 모바일 카메라 직접 촬영, 클립보드 붙여넣기(`Ctrl+V`) 지원.

2. **교과서 스타일 3단계 정리**
   - **1단계 (문장별 정밀 독해)**: `<ruby>` 태그를 통한 한자 위 요미가나 표기, 자연스러운 한국어 번역, 직역(어순 파악용), 문맥/뉘앙스 해설.
   - **2단계 (핵심 어휘)**: 단어 원형, 요미가나, 품사, JLPT 등급(N5~N1), 본문 뜻 풀이.
   - **3단계 (구문 및 문법)**: 복합동사, 조사 활용, 핵심 문형의 결합 원리와 뉘앙스 해설.

3. **학습자 친화형 편의 기능**
   - 🔊 **일본어 음성 듣기 (TTS)**: 문장별, 단어별 일본어 원어민 발음 재생.
   - 👁️ **후리가나 켜기/끄기 토글**: 독해 자가 테스트 시 후리가나를 가릴 수 있음.
   - 📥 **단어장 내보내기**: 추출된 어휘 목록을 CSV 파일로 다운로드 (Anki 등 플래시카드 앱과 연동 가능).
   - ⚡ **체험용 샘플 모드**: API 키 없이도 완성된 교과서 화면을 즉시 확인할 수 있는 샘플 데이터 탑재.

## 🚀 실행 방법

### PC에서 실행하기
* `start.bat`을 더블 클릭하거나, `index.html`을 Chrome 또는 Edge 브라우저로 열면 즉시 실행됩니다. (별도 설치 프로그램 필요 없음)

### 스마트폰에서 사용하기
* 스마트폰에서 사진을 직접 찍어 사용하려면:
  1. 이 폴더를 GitHub 저장소에 올린 후 **GitHub Pages** 또는 **Vercel**에 1분 만에 무료 배포하여 접속하거나,
  2. 같은 Wi-Fi 환경에서 로컬 서버를 열어 스마트폰 브라우저로 접속할 수 있습니다.

---

## 🔑 Gemini API 키 발급 및 설정

1. [Google AI Studio (무료 API 키 발급)](https://aistudio.google.com/app/apikey) 접속 후 로그인.
2. **Create API key** 버튼을 눌러 키 생성 및 복사.
3. 앱 상단의 **[API 키 설정]** 버튼을 눌러 붙여넣고 저장.
   *(입력한 키는 외부 서버로 전송되지 않고 본인의 웹 브라우저 로컬 저장소에만 안전하게 보관됩니다.)*
